Stale Plex versions

Versions Plex shows as "Unavailable" next to a working one. A scan only lists them; removing re-checks every guard first: Plex marked the version unavailable, its file is gone from disk, no Arr still tracks that file, the title keeps a working version, and nobody is playing it. Titles whose every version is unavailable are listed for review and never removed here.
